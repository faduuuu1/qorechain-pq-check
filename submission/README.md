# Submission materials

Everything the fest's project form asks for, prepared ahead of filling it in.

| File | What it is |
| --- | --- |
| `project-entry.md` | Every form field, paste-ready, including which kits and network features to tick and which to leave alone |
| `featured.png` | The featured image: 1280×720 PNG, 16:9, 285 KB — inside the fest's limits |
| `featured.html` | The HTML the image was designed in |
| `render.mjs` | Draws the image on a canvas at exactly 1280×720 and writes the PNG. `node render.mjs`, then open `localhost:8778` |
| `video-script.md` | A 2:45 shot list for the required video, under the 3:00 limit |

The image is generated rather than hand-exported so it can be reproduced at the
exact size the form checks for.
